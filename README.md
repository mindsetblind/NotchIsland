# NotchIsland

Интерактивный Dynamic Island для MacBook с вырезом (Swift + SwiftUI; единственная зависимость — Sparkle для автообновлений).

## Установка

1. Открой [последний выпуск](https://github.com/mindsetblind/NotchIsland/releases/latest) и скачай **`NotchIsland.dmg`** (остальные файлы выпуска нужны только для обновлений).
2. Открой образ и перетащи NotchIsland в «Программы».
3. Запусти. Приложение не нотаризовано Apple, поэтому macOS сначала откажется его открывать: зайди в **Системные настройки → Конфиденциальность и безопасность**, пролистай вниз и нажми **«Всё равно открыть»** (один раз).
4. Остров появится у выреза; настройки — правый клик по острову → «Настройки…».

Дальше NotchIsland обновляется сам. Нужна macOS 14 или новее, Apple Silicon или Intel.

Для pet-помощника (⌥⇧Space) вставь в настройках бесплатный ключ [Groq](https://console.groq.com/keys) — или выбери Ollama / Claude Code. Для плейлистов Spotify нужен свой Client ID (см. «Плейлист Spotify» ниже).

> **Почему не Docker?** Docker-контейнеры работают на Linux, а NotchIsland — приложение macOS (AppKit, SwiftUI, Core Animation): в контейнере его нельзя ни собрать, ни запустить. Вместо образа — готовый `.dmg` и автообновления; собрать самому можно на любом Mac (ниже).

## Возможности

- **Свёрнут** — выглядит как обычный вырез.
- **Играет музыка** (Spotify / Apple Music) — обложка слева от выреза, эквалайзер справа.
- **Наведение курсора** — остров слегка «приподнимается»; **клик** — раскрывается: трек, прогресс, ⏮ ⏯ ⏭.
- **Плейлист** (кнопка ☰) — треки текущего плейлиста/альбома, выбор трека без открытия плеера. Для «Музыки» работает сразу через AppleScript, для Spotify — через Web API (см. ниже).
- **Вкладки** «Музыка / Приложения / Полка / Буфер / Агенты и задачи / Инструменты» в шапке — высота острова не меняется.
- **Активности** — свёрнутый остров показывает самое важное из идущего сейчас (помидор, Claude Code, сборки, музыка — порядок настраивается), а короткие уведомления (устройства, зарядка, готовая сборка…) появляются поверх по очереди и возвращают остров к живой активности. Клик по уведомлению открывает его вкладку.
- **История буфера обмена** (вкладка «Буфер», выключена по умолчанию) — текст и ссылки, клик копирует снова, закрепление, удаление, поиск в отдельной панели (⌃⌥V по желанию). Хранится только на этом Mac; пароли из менеджеров паролей и вероятные токены не записываются.
- **Developer Mode** (выключен по умолчанию) — сборки, тесты, скрипты и серверы из любого терминала или IDE: спиннер с таймером у выреза, «готово» или ошибка по завершении. `notchisland-cli run -- swift build`, формат событий — [docs/developer-mode.md](docs/developer-mode.md).
- **Системные уведомления** — низкий заряд (20 % и 10 %), мало места на диске, завершённые загрузки и ближайшие события календаря (последние два — по желанию, с разрешением macOS).
- **Помидор** (вкладка «Инструменты») — 25/5/15 (или 50/10, 15/3), кольцо и время у выреза, звук и уведомление по окончании этапа, счётчик 🍅 за день.
- **Чистка** (вкладка «Инструменты») — чёрный экран на всех дисплеях, клавиатура и трекпад отключены на 2 минуты (30 с / 1 мин в меню), выход — удерживать Esc 2 с. С разрешением «Универсальный доступ» блокируются и клавиши яркости/громкости.
- **Пипетка** (вкладка «Инструменты») — цвет с любой точки экрана → HEX в буфере обмена, история цветов, копирование в rgb(…) / SwiftUI.
- **⌥Space** — открыть/закрыть остров с клавиатуры.
- **Приложения** — быстрый запуск и переключение (точка — приложение запущено).
- **Перетаскивание файлов к вырезу** — две зоны: «Полка» и «AirDrop».
- **Полка** — файлы ждут на острове, их можно вытащить куда угодно, открыть или отправить по AirDrop.
- **Подключение устройств** — AirPods и другие Bluetooth-устройства, флешки и внешние диски: иконка, название, заряд.
- **Pet** — всегда живёт справа от выреза: моргает, следит за курсором, под музыку глаза прыгают как эквалайзер, «думает», пока работает Claude Code, зовёт, когда тот ждёт ответа, засыпает, если долго не трогать Mac. Анимации на Core Animation.
- **Pet-помощник** — по ⌥⇧Space pet вылезает из выреза с полем ввода и помогает с файлами: найти, разложить по папкам, переименовать, сжать, убрать в Корзину. Ещё включает музыку в Spotify по просьбе («включи Radiohead», «что-нибудь спокойное»): ищет через Web API и запускает в приложении Spotify, Premium не нужен. Источник можно указать тегом: под полем чипы «Любимые треки» и твои плейлисты, а по `@` — поиск по плейлистам, альбомам и любимым; один тег и ⏎ включает его сразу, тег с текстом («@Для бега что-нибудь бодрое») — Claude выбирает трек именно оттуда. Простые просьбы выполняются мгновенно, без Claude: «пауза», «дальше», «назад», «включи <название>» (сначала твоя медиатека, потом поиск Spotify), «найди <имя файла>» (Spotlight). Для остального Claude Code запускается заранее, пока ты печатаешь, — ответ примерно втрое быстрее. Голосом: удерживай ⌥⇧Space и говори — речь распознаётся прямо на Mac, отпустил — запрос ушёл (или кнопка микрофона в панели). Сам предлагает помощь: изредка (не чаще раза в 3 часа, одно и то же — раз в неделю) смотрит на Загрузки и Рабочий стол и, если там копятся старые файлы, скриншоты или установщики, показывает в острове короткое предложение; клик открывает pet с готовым запросом. Учитывает открытую папку и выделение в Finder, файлы можно перетащить прямо на него. Думает через выбранную модель: **Groq** (по умолчанию — ответ за доли секунды, бесплатный ключ с console.groq.com/keys вставляется в настройках и хранится в Связке ключей), **Ollama** (модель на этом Mac, без интернета) или **Claude Code** (`claude -p` только с инструментами чтения, по твоей подписке). Модели доступны только инструменты чтения (список папки, Spotlight, начало текстового файла), сам pet ничего не меняет: сначала показывает план, выполняет после ⏎, сделанное можно отменить. Работает только в домашней папке, кроме ~/Library и скрытых файлов.
- **Claude Code** — статус сессий у выреза («думает», «готово», «ждёт ответа»), вкладка с сессиями и подтверждение разрешений прямо из острова (через хуки, `Hook/`).
- **Пробел** — пауза/воспроизведение, пока остров раскрыт на вкладке «Музыка».
- **Подключение зарядки** — короткое уведомление с процентом заряда.
- **Reduce Motion** — с включённым «Уменьшить движение» пружины и размытия заменяются на короткое затухание, pet только моргает.
- **Настройки** (⚙︎ в шапке или правый клик → «Настройки…») — способ раскрытия (клик/наведение), ⌥Space, какие уведомления показывать, Spotify, картинка-заглушка вместо обложки, помидор и чистка.
- **Правый клик** — настройки, Spotify Client ID, «Запускать при входе», «Выйти».

## Сборка и тесты

Требуется macOS 14+ и Xcode (или Command Line Tools). Сборка из исходников на своём Mac:

```bash
git clone https://github.com/mindsetblind/NotchIsland.git
cd NotchIsland
./build.sh --install
```

Остальные команды:

```bash
./build.sh            # собрать NotchIsland.app в папке проекта
./build.sh --install  # собрать, установить в /Applications и запустить
swift test            # модульные тесты логики (NotchIslandCore)
```

`build.sh` подписывает приложение сертификатом Apple Development / Developer ID из Связки ключей, если он есть (или `SIGN_IDENTITY=...`), — тогда выданные разрешения сохраняются между пересборками. Без сертификата — ad-hoc подпись.

При первом треке macOS попросит разрешить управление Музыкой/Spotify — нажми «Разрешить».

## Плейлист Spotify

Список треков берётся из Spotify Web API, поэтому нужен свой Client ID:

1. Создай приложение на [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard).
2. Redirect URI: `http://127.0.0.1:8973/callback`, API: Web API.
3. Правый клик по острову → «Spotify Client ID…» → вставь Client ID, затем нажми ☰ → «Войти в Spotify».

Client Secret не нужен (OAuth PKCE), токен хранится в Связке ключей.

Ограничения Spotify для приложений в режиме разработки:
- выбор трека в своих плейлистах и альбомах идёт через Web API и требует **Premium**;
- чужие и алгоритмические плейлисты Spotify читать не даёт — для них показывается «Далее в очереди», а выбор трека выполняется перелистыванием (next/previous) до нужного.

## Видео вместо обложки

Пока обложка грузится, показывается картинка, выбранная в Настройках → «Музыка» (хранится в `~/Library/Application Support/NotchIsland`). Можно также положить `Resources/placeholder.jpg|png` или зацикленное видео `Resources/placeholder.mp4` (в git не попадают) и пересобрать. Без них — градиент с нотой.

Диагностика Spotify пишется в `~/Library/Logs/NotchIsland.log` (не больше ~256 КБ, затем ротация).

## Снимки интерфейса и анимаций

- `./NotchIsland.app/Contents/MacOS/NotchIsland --snapshots <папка>` — рисует все состояния острова в PNG на тестовых данных и завершается.
- `./NotchIsland.app/Contents/MacOS/NotchIsland --capture-collapse <папка>` — раскрывает и сворачивает остров на сером фоне и сохраняет все кадры сворачивания одной картинкой.
- `--capture-tabs <папка>` — все вкладки раскрытого острова из настоящего окна (в отличие от `--snapshots`, со списками и прокруткой).
- `--capture-search <папка>` — панель поиска по истории буфера на тестовых данных (ввод, выбор стрелками).

## Производительность и приватность

- Постоянные анимации (pet, эквалайзер, спиннер) — на Core Animation, без перерисовки SwiftUI.
- Плеер обновляется по системным уведомлениям Spotify/«Музыки»; опрос через AppleScript — раз в секунду только при открытом плеере, иначе раз в 10–30 с. Зависший плеер не блокирует очередь (таймаут 3 с) и опрашивается с нарастающей паузой; нет доступа к «Автоматизации» — остров так и говорит.
- Батарея — по событиям IOKit, буфер обмена — только `changeCount` раз в секунду и только когда история включена.
- Никакой телеметрии. Сеть используется только для Spotify Web API и обложек Spotify (в памяти, до 30 штук).
- Локальный сокет (`~/Library/Application Support/NotchIsland/claude.sock`, права 0600, проверка UID собеседника) — для хуков Claude Code и Developer Mode; полученное никогда не исполняется.

## Обновления

NotchIsland обновляется сам (Sparkle): раз в день проверяет `appcast.xml` в последнем выпуске на GitHub, скачивает новую версию, проверяет её EdDSA-подпись и устанавливает. В настройках можно выключить автопроверку или разрешить установку без вопросов; в меню острова — «Проверить обновления…».

Выпустить новую версию:

```
./release.sh 1.2 "Что нового"
```

Скрипт поднимает номер версии в `Info.plist`, собирает универсальное приложение, подписывает архив ключом обновлений, коммитит, ставит тег, пушит и создаёт выпуск на GitHub (zip для обновлений, dmg для новых пользователей, `appcast.xml`). С `--dry` только собирает всё в `dist/`.

Ключ подписи обновлений лежит в Связке ключей (создан Sparkle `generate_keys`). Без него выпустить обновление нельзя — сохрани резервную копию: `.build/artifacts/sparkle/Sparkle/bin/generate_keys -x ключ.txt` и убери файл в менеджер паролей.

## Поделиться с другом

```
./package.sh
```

Соберёт `dist/NotchIsland.dmg`: универсальную версию (Apple Silicon и Intel, macOS 14+) без твоей картинки-заглушки и с файлом «Как открыть». Приложение не нотаризовано, поэтому при первом запуске нужно нажать «Всё равно открыть» в Системных настройках → Конфиденциальность и безопасность.
